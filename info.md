# Kelvinator Climate Component

Local control for Kelvinator/Electrolux air conditioners with a Broadlink
OEM Wi-Fi module — no cloud round-trip.

**Fork of [DotEfekts/ElectroluxClimateComponent](https://github.com/DotEfekts/ElectroluxClimateComponent)**,
renamed for Kelvinator branding and with stability fixes applied (blocking
I/O removed from setup, graceful handling of the AC's own brief Wi-Fi
reconnects, a couple of bug fixes). See
[CHANGELOG.md](https://github.com/Elliottmonaghan/KelvinatorClimateComponent/blob/master/CHANGELOG.md)
for details.
